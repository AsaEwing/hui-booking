產生抽籤簽章金鑰

這是部署時用一次的工具，不是給學生或一般使用者用的頁面。用來產生「抽籤結果數位簽章」功能需要的一組金鑰 （ECDSA P-256）。這個功能是選用的：不設定也完全不影響系統運作，只是抽籤紀錄不會有數位簽章可供驗證。 如果你還不確定要不要用這個功能，可以先跳過，之後隨時可以回來產生。

🔒 所有運算都在你自己的瀏覽器裡完成，金鑰不會被傳到任何伺服器。但也因為這樣，這個頁面不會幫你保存金鑰—— 重新整理或關掉分頁，剛剛產生的金鑰就會遺失，請務必先把私鑰複製、貼到 Cloudflare 的密碼設定裡再離開。

已經有一組在用的金鑰了嗎？重新產生會是完全不同的一組，之前簽過的抽籤紀錄會變成「無簽章可驗證」（不會出錯， 只是少了那道防偽保障），沒事不需要重新產生。

1  私鑰 — 貼到 Cloudflare 的密碼設定

到 Cloudflare Dashboard → 你的 Pages 專案 → Settings → Environment variables，新增一個 Secret，名稱填 LOTTERY_SIGNING_KEY，值就貼下面這一整行。 這是機密資料，只能貼在 Cloudflare 的密碼設定裡，絕對不要貼到程式碼、GitHub、或傳給任何人。

2  公鑰 — 貼到 verify-lottery.html 裡

公鑰不是機密資料，可以放心公開。用 GitHub 網頁編輯器打開你 repo 裡的 public/verify-lottery.html，找到 LOTTERY_PUBLIC_KEY_JWK 這一行，整行換成下面這段， 存檔（commit）後 Cloudflare 會自動重新部署。

⚠️ 兩個步驟都做完、確認 Cloudflare 已經重新部署之後，才可以離開這個頁面。金鑰只會顯示這一次。
